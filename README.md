# HYPNOTHESE — L’heure de silence

Page pratique et livret pour le site [hypnothese.fr](https://hypnothese.fr).

## Fichiers

- `heure-de-silence/index.html` — studio guidé (modules + exercices)
- `heure-de-silence/livret-heure-de-silence.pdf` — livret imprimable (ajouter via l’interface GitHub si besoin)
- `heure-de-silence/livret-heure-de-silence.docx` — version Word

## Mise en ligne

Copier le dossier `heure-de-silence/` dans `public/` du site, ou créer la route `/heure-de-silence` et le lien dans le menu à côté de « Rêves & psyché ».
